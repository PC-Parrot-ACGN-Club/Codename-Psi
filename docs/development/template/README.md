# 开发设计模板

复制与当前设计范围匹配的模板，保留元数据、Test Basis 与验收条件。

| 文档类型 | 适用范围 | 模板 |
| --- | --- | --- |
| Component Spec | 单模块行为、规则、数据模型与公开能力。 | [component-spec.md](component-spec.md) |
| Component Integration Contract | 组件之间的接口、数据交换与协作时序。 | [component-integration-contract.md](component-integration-contract.md) |
| System Architecture 与 Flow | 跨 crate 架构、状态流与完整用户流程。 | [system-architecture-flow.md](system-architecture-flow.md) |
| Decision | 经审核的设计选择与后续动作。 | [decision.md](decision.md) |

分类定义与审核规则见[开发设计分类与模板](../README.md)。

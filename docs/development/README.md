# 开发设计文档

**适用范围：** 本项目的模块设计、跨模块架构与设计决策

写作规则见[文档写作规范](../CONVENTIONS.md)。模板见[模板目录](template/README.md)。

## 文档类型

| 类型 | 一份文档覆盖 | 目录 |
| --- | --- | --- |
| 模块设计 | 一个主题：数据模型、行为、跨模块协作与边界。主题跨几个模块不影响它是一份文档。 | `design/` |
| 架构总览 | 一个跨模块运行面：模块职责、依赖方向与主流程。 | `system/` |
| 决策 | 存在真实备选方案、需要保留取舍理由的选择。 | `decision/` |

默认写模块设计。只有在描述多个主题如何组成一条运行路径时才写架构总览。

## 与测试文档的关系

设计文档定义行为和边界；可判定的断言由[测试用例设计](../test/README.md)承担。
测试稿的「关联设计」字段建立从测试到设计的反向链接，设计文档不重复列出验收条件。

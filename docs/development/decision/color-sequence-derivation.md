# DEC-005：两名玩家的颜色序列完全独立派生

**关联文档：** [确定性、快照与状态校验](../design/determinism-and-snapshot.md)、[玩法设计 §3.2、§3.3](../../gameplay.md)

## 背景

活动组的形状来自角色掉落组，颜色来自对局随机流。两名玩家的颜色序列可以共享、可以按手号对齐，也可以各自独立派生。该选择既影响单场公平感，也影响回滚时两名玩家状态的耦合程度。

两名原创角色的掉落组形状分布不同——一方三个三球手、另一方一个，且四球手的单双色构成也不同。因此两人在同一手号上的形状本就不同，每手消耗的颜色个数也随之不同。

## 决策

每名玩家各持一组独立的命名随机流，派生键包含 participant slot：

```text
derive(round_index, draw_attempt, player_slot, stream_name)
```

单场对局中两人的颜色序列互不相同也互不影响。掉落组与连锁曲线的平衡性由[玩法设计 §3.2、§3.3](../../gameplay.md) 规定的双方换边胜率样本验证，而不依赖颜色序列相同。

## 依据

- [玩法设计 §3.2](../../gameplay.md)：颜色随机流及其位置属于对局状态而非静态掉落组，因此颜色与形状本就分属两个来源。
- [玩法设计 §3.3](../../gameplay.md)：角色平衡以换边胜率样本验证，样本量而非单场对称性承担公平性。
- [TDD §6](../../TDD.md)：规则状态需支持深拷贝与回滚；独立流使两名玩家的随机状态互不纠缠。

## 备选方案

| 方案 | 适配条件 | 影响 |
| --- | --- | --- |
| 共享单一流、按消费顺序推进 | 两人消耗节奏一致 | 谁先落子决定谁先取色，玩家操作速度改变对手的颜色；回滚时两人的流位置互相纠缠 |
| 同一序列、双方按各自手号索引 | 两人每手消耗的颜色个数一致 | 形状分布不同使同一手号的局面并不对称，公平收益是名义上的；且需额外规定每手固定消耗几个颜色、单双色决定从哪条流取，这两项都不可观察却进入校验和 |
| 完全独立派生（已选） | 接受单场序列不同，由样本量保证平衡 | 无跨玩家耦合，派生键形式与小局重打的派生模型一致 |
